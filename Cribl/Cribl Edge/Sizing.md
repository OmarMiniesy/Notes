##### Leader Node

**CPU**:
- Minimum 4 vCPU
- Recommended 8 vCPU

**RAM**:
- Minimum 8GB
- Recommended 16GB

> These requirements should increase with more edge nodes. Add 2 GB of RAM and 1 vCPU for every 10,000 edge nodes.

##### [[Edge]] Nodes

**CPU**:
- only 1 CPU core.
- [[Kubernetes]] supports 2 CPUs

**RAM**:
- Minimum 512MB
